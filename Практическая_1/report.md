# Практическая 1

## Тема

Каталог курсов на Django.

## Реализация

Создано приложение catalog с данными в константах AUTHORS и COURSES. Представления передают словари в шаблоны, маршруты курса и автора получают pk. Реализованы все семь типов страниц из задания. Неизвестные id и адреса возвращают HTTP 404 с собственным оформлением.

В финальном проекте доступ требует входа по последующим заданиям. Данные самого каталога не перенесены в БД; учебная система расположена отдельно в schedule.

## Файлы

../django_project/catalog/; ../django_project/templates/base.html.

## Проверка и демонстрация

Войти как editor. Открыть /, /courses/, /courses/1/, /authors/, /authors/1/, /info/ и несуществующий адрес. Файлы catalog/data.py, urls.py, views.py показать в этом порядке.

Фактические результаты общего прогона сохранены в `../ПРОВЕРКА.txt`.

## Объяснение

Model/View/Template разделяют данные, обработку запроса и представление. Конвертер int в URL даёт числовой параметр view. Для 404 сервер работает с DEBUG=False.
