# Лабораторная 1 — Работа с внешним API

Исходное задание: `задание.pdf`.

Код: main.py; test_api.py; cache/; results/. Пути после первого `../django_project/` в перечислении относятся к этому проекту.

Из корня: `python run.py api`. Открыть пять PNG в results. Для обновления: `python Лабораторная_1/main.py --refresh`. Тесты: `python -m pytest -q Лабораторная_1`.

Подробности и объяснение: `report.md`. Общий запуск описан в корневом README.md.
