# Лабораторная 1

        Тема: работа с данными внешнего API и построение графиков.

        Что находится в папке:

        - `задание.pdf` - исходное задание;
        - файлы решения или ссылка на общий Django-проект;

        Запуск/проверка:

        ```bash
        python3 -m pip install -r requirements.txt
python3 main.py
        ```
