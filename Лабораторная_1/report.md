# Лабораторная 1

## Тема

Работа с внешним API.

## Реализация

Получены первые 10 Pokémon через requests. collect читает список, parse_pokemon извлекает характеристики по именам stats. Сохраняются исходные ответы и итоговый JSON. Ошибки HTTP, таймаут, отсутствующий кэш и неверный JSON дают понятную ошибку.

Построены линейный график HP/attack/defense, scatter роста и массы с цветом скорости, столбчатая атака, гистограмма массы и доли основных типов. Подписи включают единицы; в scatter подписи разведены по вертикали. Данные являются реальной выборкой API, а не вымышленными значениями.

## Файлы

main.py; test_api.py; cache/; results/.

## Проверка и демонстрация

Из корня: `python run.py api`. Открыть пять PNG в results. Для обновления: `python Лабораторная_1/main.py --refresh`. Тесты: `python -m pytest -q Лабораторная_1`.

Фактические результаты общего прогона сохранены в `../ПРОВЕРКА.txt`.

## Объяснение

Почему данные stats ищутся по имени? Порядок в JSON не является идентификатором характеристики. Почему две единицы измерения? В API рост в дм, масса в гектограммах; на графике используются метры и килограммы.
