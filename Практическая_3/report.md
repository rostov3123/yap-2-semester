# Практическая 3

## Тема

Профили и друзья.

## Реализация

При регистрации обязательны email и телефон; после успешной регистрации выполняется login. Участник видит свой профиль, может редактировать только себя, просматривает список пользователей и профили друзей. Чужой незнакомый профиль возвращает 403.

Связь friends симметрична. Добавление и удаление выполняются POST, нельзя добавить себя. Анонимы перенаправляются на вход; доступны только регистрация и необходимые auth-процессы. Проверка прав действует и на файл аватара, а не только на HTML-профиль.

## Файлы

../django_project/users/models.py; forms.py; views.py; middleware.py.

## Проверка и демонстрация

Войти как student. friend уже доступен; stranger закрыт. Добавить stranger, открыть профиль, удалить из друзей и повторить прямой переход. Подставить чужой id в /users/id/edit/: получить 403.

Фактические результаты общего прогона сохранены в `../ПРОВЕРКА.txt`.

## Объяснение

Скрыть ссылку недостаточно: доступ проверяется во view. Симметричная M:N отражает дружбу в обе стороны. В учебной версии нет подтверждения заявки; это явно указано пользователю.
