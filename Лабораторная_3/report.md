# Лабораторная 3

## Тема

Шаблоны и обычные формы.

## Реализация

В base.html применены header, nav, main, footer и block content. Навигация содержит списки и добавление преподавателя/курса. Список преподавателей размечен section/article, выводит ФИО, email и курсы; предусмотрено пустое состояние.

TeacherForm наследуется от forms.Form. Поля имеют label, help_text, placeholder; department необязательно. GET отдаёт пустую форму, POST привязывает данные, is_valid проверяет их, затем запись сохраняется. Ошибки отображаются form.as_p. Эта форма сохранена в финальном проекте по отдельному адресу.

## Файлы

../django_project/templates/base.html; templates/schedule/teachers.html; schedule/forms.py; schedule/views.py.

## Проверка и демонстрация

Войти как editor, открыть /schedule/teachers/add-basic/. Отправить пустую форму, затем неправильный email, затем корректные данные. В основной форме /add/ уже показано продолжение из ЛР4.

Фактические результаты общего прогона сохранены в `../ПРОВЕРКА.txt`.

## Объяснение

Bound form содержит данные POST и ошибки; unbound form показывает пустые поля. csrf_token нужен для изменяющих запросов. Redirect после сохранения предотвращает повторную отправку POST при обновлении страницы.
