# ЯП 2 семестр

Локально подготовлены решения лабораторных и практических работ.

- `Лабораторная_1` - PokeAPI, JSON, matplotlib-графики.
- `Лабораторная_2` - регулярные выражения.
- `Практическая_1` - Django MVT и каталог курсов.
- `Практическая_2` - модели `schedule`, связи 1:1, 1:N, N:N и CRUD.
- `Лабораторная_3` - базовый шаблон, список преподавателей и форма.
- `Лабораторная_4` - ModelForm, ограничения и валидаторы.
- `Лабораторная_5` - кастомный пользователь, регистрация, auth urls, файловая почта.
- `Практическая_3` - профиль, друзья, ограничения доступа.
- `Лабораторная_6` - pytest/pytest-django тесты.
- `Лабораторная_7` - логирование, обработчики и форматтеры.

Django-код находится в `django_project`, потому что несколько работ последовательно развивают один проект.
