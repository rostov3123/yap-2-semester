# Языки программирования — второй семестр

Новый комплект: 7 лабораторных, 3 практические и итоговый Django-проект «Академия».
Задания сохранены без изменений. Каждая папка содержит исходный PDF, описание реализации и сценарий демонстрации. Веб-работы последовательно развивают один сайт в `django_project`; код не дублируется между папками.

## Начало работы

Сначала откройте `00 СНАЧАЛА ПРОЧИТАТЬ.txt`. Логины и пароль находятся в `01 ДОСТУП К САЙТУ.txt`.

## Первоначальная установка

Проверено на Python 3.12. Версии зависимостей зафиксированы в `requirements-lock.txt`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python run.py setup
python run.py serve
```

Windows: вместо `python3` используйте `py -3.12`, вместо `source ...` — `.venv\Scripts\activate` (cmd) или `.venv\Scripts\Activate.ps1` (PowerShell).
Первый `setup` требует интернет для установки зависимостей. Последующие демонстрации сайта и API из кэша работают без сети.
`setup` применяет миграции и добавляет вымышленные демонстрационные данные. Он не очищает БД и не меняет пароли существующих аккаунтов.

## Демонстрационные аккаунты

Общий пароль: `DemoStudy!2026`. Только для локальной учебной базы.

| Логин | Назначение |
| --- | --- |
| editor | Создаёт, изменяет и удаляет преподавателей, курсы и студентов |
| student | Обычный участник, уже дружит с friend |
| friend | Друг student; доступен взаимный просмотр профилей |
| stranger | Незнакомый участник для проверки отказа в доступе |

Редактор не является суперпользователем. Для отдельного администратора при необходимости: `python django_project/manage.py createsuperuser`.

## Команды проверки и демонстрации

Команды ниже выполняются с активированным окружением:

```bash
python run.py test
python run.py api
python run.py regex
python Лабораторная_1/main.py --refresh
python Лабораторная_7/basic_logging.py
```

`api` строит пять графиков по сохранённым реальным ответам PokéAPI, `--refresh` обновляет ответы из сети.
Для повторной загрузки иного количества: `python Лабораторная_1/main.py --limit 20` (кэш соответствует URL с этим limit).
Все результаты ЛР1 находятся в `Лабораторная_1/results`, исходные ответы — в `Лабораторная_1/cache`.

## Существенные особенности

- Каталог первой практической хранит данные в константах. Учебные записи schedule хранятся в SQLite: это два разных раздела по требованиям двух этапов.
- ЛР3 доступна отдельным маршрутом `/schedule/teachers/add-basic/`; основная форма добавления является ModelForm из ЛР4.
- Пять новых полей добавляет `schedule/migrations/0002_lab4_constraints.py`.
- Анонимам доступны регистрация, вход и восстановление пароля. Эти технически необходимые маршруты позволяют выполнить требование о закрытых остальных страницах.
- Дружба взаимная и добавляется сразу, без заявок; такой упрощённый механизм соответствует заданию. После удаления дружбы доступ закрывается в обе стороны.
- Учебные изменения доступны пользователям с Django permissions; editor получает их через группу. Скрытые кнопки дублируются серверной проверкой прав.
- Аватары выдаются через защищённое представление, а не через публичную папку media.
- Письма восстановления лежат в `django_project/sent_emails`. В письме есть настоящая локальная ссылка; SMTP не используется.
- `DEBUG=False` позволяет показать собственную страницу 404. `run.py serve` применяет `--insecure` только для раздачи CSS локальным сервером Django. Это конфигурация локальной демонстрации, не публичного размещения.
- Данные и файлы пользователя, БД, логи и окружение исключены из Git. Снимки данных API и графики включены как результаты лабораторной.

Официальные справочники: https://docs.djangoproject.com/en/5.2/ и https://pokeapi.co/docs/v2 . Приоритет в составе работ имеют приложенные задания преподавателя.
