# Лабораторная 2

## Тема

Регулярные выражения.

## Реализация

Созданы шесть отдельных функций: validate_login, find_dates, parse_log, validate_password, validate_email, normalize_phone. Все используют re. Проверки дат и IPv4 дополняют синтаксис семантикой. Для неправильного лога и телефона поднимается ValueError; функции проверки возвращают bool, поиск дат возвращает список.

Двузначные годы означают 2000–2099. Email поддерживает обычную ASCII dot-atom запись; разрешённый домен сравнивается целиком без учёта регистра. Входной IP сохраняется, несмотря на опечатку выходного примера задания.

## Файлы

main.py; test_regex.py.

## Проверка и демонстрация

Из корня: `python run.py regex`; затем `python -m pytest -q Лабораторная_2`. Показать границы длины логина 4/5/20/21, ошибочную дату 31.02, смешанные разделители, домен gmail.com.evil.org и незакрытую скобку в телефоне.

Фактические результаты общего прогона сохранены в `../ПРОВЕРКА.txt`.

## Объяснение

fullmatch проверяет всю строку. Группа обратной ссылки требует одинаковый разделитель даты. Lookahead проверяет наличие признака пароля, не потребляя символы.
